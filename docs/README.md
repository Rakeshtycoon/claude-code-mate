## The one-paragraph summary

A diamond's reported facet angles are **averages**; individual facets can vary. Symmetry is set
mechanically by each facet's **angle** (mast/protractor) and **azimuth** (index wheel, 3.75°/tooth),
cut to **meet points** — created at bruting/blocking and refined at brillianteering. Cutters can
**manipulate** the small girdle facets (**painting/digging**, ±11.25°) to retain weight or tune
light while keeping the main-angle averages "ideal," which can pass a symmetry grade yet fail a
light-performance grade. To **maximize light**, facet angles are optimized with ray-tracing software
(**OctoNus DiamCalc**, Sarine Light/Advisor, AGS ASET) and verified with ASET/Ideal-Scope/Hearts &
Arrows. Modern CNC/laser systems make all of this repeatable at micron/sub-degree precision.
